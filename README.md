# useful tools (but vibe coded)
### minecraft-text-designer.html
in here you can plan the design of
the item lore of your custom items,
your titles and subtitles,
your chat messages,
your book pages.
it should be very intuitive but it doesnt generate commands yet because i only use it for planning.
the preview should match exactly how minecraft displays it.

### minecraft-unifont-map.html
this is the whole unifont map with the two fonts that minecraft use: mojangles and the backup unifont 17 i think.
incase you need a symbol for your custom lore or chat messages just look at this giant map and copy it. you can fav symbols, isolate them and the preview should match exactly how minecraft displays it.
